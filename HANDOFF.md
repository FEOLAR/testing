## 1. Что это
VPN-сервис **WhiteHoleVPN** (раньше GalacticVPN), продажа через Telegram-бота **@WhiteHoleVPNbot** + мини-приложение.
Цель — ~1000 устройств. Владелец: @FEOLAR. Старый бот (legacy) отвечает «мы переехали» и шлёт в новый.

## 2. Код
- Репозиторий: `FEOLAR/testing`, ветка **`claude/galacticvpn-project-hw65vu`** (всё запушено). PR не создавать без просьбы.
- `bot/app/` — бот (aiogram 3, aiohttp, SQLAlchemy async + PostgreSQL, Redis, docker compose).
- `infra/add-node.sh` — установка новой ноды (Docker, remnanode NODE_PORT 2222, sub-proxy Caddy :9443, ufw); `bash add-node.sh test` — тест TLS.
- `infra/bridge-nodes.sh` — мост в РФ: проверка нод, HAProxy (balance source) 443/8443, Caddy для подписки.
- Последний архив: **whitehole-bot-v40.zip** (v38 установлена 21.10; v39/v40 — к установке).

## 4. iPhone: отключения VPN (решено)
Причина — лимит памяти iOS 50 МБ: geo-базы runetfreedom в профиле маршрутизации. Заменили заголовок подписки `routing`
на лёгкий профиль Happ без geoip/geosite (только domain:ru/su/рф + список доменов, DNS Cloudflare DoH + Яндекс),
телефонам — TCP+Vision (сервер «📱»). Подтверждено конфигом с iPhone: geo нет, flow vision есть.

## YouTube-реклама: итоги расследования (17.10.2026)
- Причина: Google считает IP наших нод зарубежными (GL: FR-1=FR, GE-1=DE, панель=NL, FI-сервер Hostkey=FI). Реклама пропадает только при российском GL.
- Конкурент без рекламы: обычный конфиг (всё через VPN, кроме RU-сайтов, UDP/443 block), выход 89.124.95.95 — AS216071 SERVERS TECH FZCO (VDSina, Амстердам), Google считает RU.
- Проверено: прямой выход youtubei.googleapis.com / www.youtube.com с телефона убирает рекламу на Wi-Fi, но на мобильном интернете YouTube не грузится — клиентский вариант (профили test A–E) отвергнут. Старый профиль GalacticVPN RU-direct тоже с рекламой.
- В Config Profile нод добавлено: блок geosite:category-ads-all и блок UDP/443 (QUIC). Оставить.
- План: сервер с GL=RU (VDSina NL) → infra/yt-exit.sh (Shadowsocks-2022 :8388, доступ только FR-1/GE-1) → outbound YT_RU + balancer YT_BAL (fallbackTag DIRECT, observatory) для full:www.youtube.com, m.youtube.com, youtube.com, s.youtube.com, youtubei.googleapis.com.
