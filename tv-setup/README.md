# WhiteHole Setup — программа для Windows

Делает в пару кликов всё, что раньше делали руками через ADB:
находит телевизор в домашней сети, ставит лаунчер WhiteHole (VPN в нём уже встроен),
делает WhiteHole домашним экраном, может заранее разрешить VPN, а на старых ТВ — поставить Happ,
на Яндекс ТВ — убрать рекламу (и вернуть всё обратно).

## Где скачать

Последняя сборка всегда здесь:
https://github.com/FEOLAR/testing/releases/tag/tv-setup-latest

Прямая ссылка на файл:
https://github.com/FEOLAR/testing/releases/download/tv-setup-latest/WhiteHoleSetup.exe

Это один файл `WhiteHoleSetup.exe` (~20–30 МБ), установка не нужна: adb уже внутри.

### Предупреждение Windows (SmartScreen)

Программа не подписана сертификатом, поэтому при первом запуске Windows может показать
синее окно «Система Windows защитила ваш компьютер». Нажать **«Подробнее» → «Выполнить в любом случае»**.
Браузер (Chrome/Edge) тоже может спросить «Сохранить файл?» — выбрать «Сохранить» / «Всё равно сохранить».
Убрать предупреждение навсегда можно только платным сертификатом подписи кода.

## Что делает программа

1. **Найти телевизор** — сначала показывает уже известные adb телевизоры, потом проверяет адреса из
   `arp -a`, потом все частные подсети /24 настоящих адаптеров (Wi-Fi/Ethernet со шлюзом — первыми;
   Hyper-V/WSL/VirtualBox/VPN — в конце, 198.18.x TUN пропускается). Порт 5555 проверяется по протоколу
   ADB, поэтому VPN в режиме TUN не даёт ложных находок. Поиск — не дольше 20 с, есть «Отмена»;
   поле «Ввести IP вручную» работает всегда, даже во время поиска. Все адаптеры, подсети и ответы
   пишутся в «Подробности».
   Если на ТВ появилось «Разрешить отладку?» — отметить «Всегда разрешать» и нажать ОК (программа ждёт 60 с).
2. **Установить** — скачивает свежий лаунчер из релиза `tv-launcher-latest`: если там есть APK под
   процессор телевизора (`whitehole-tv-arm64-v8a.apk` / `whitehole-tv-armeabi-v7a.apk`, по
   `getprop ro.product.cpu.abi`) — его, иначе универсальный `whitehole-tv.apk`. Ставит и делает WhiteHole
   домашним экраном. **Happ по умолчанию не ставится** (VPN встроен в лаунчер): только если на ТВ
   Android 6 и ниже (SDK < 24 — галочка включается сама) или если отмечено «Также установить Happ».
3. **Вход** — подсказка клиенту: на ТВ в WhiteHole нажать «Войти через Telegram» и отсканировать
   QR-код телефоном; кнопка «Открыть WhiteHole на ТВ» (`am start -n space.whitehole.tv/.MainActivity`).
   - **Разрешить VPN заранее** (по желанию): `appops set space.whitehole.tv ACTIVATE_VPN allow` — системное
     согласие на VpnService хранится именно в этом app-op, поэтому окно «Разрешить подключение к VPN?»
     на ТВ не появляется. Проверено владельцем на Tuvio (Android 11); на некоторых прошивках может не
     сработать — тогда ТВ один раз покажет обычное окно.
   - Только если на ТВ есть Happ (старые ТВ): поле «ссылка из бота → Отправить в Happ»
     (диплинк `happ://add/<ссылка>`).
4. **Убрать рекламу** (для продвинутых) — после подключения программа определяет платформу
   (Яндекс ТВ, Google TV, Android TV, Xiaomi PatchWall, Салют ТВ, Android-приставка) и показывает
   галочками только то, что реально есть на ТВ (`pm disable-user --user 0`).
   Списки — в `whitehole_setup/profiles.py`, у каждого пакета источник и уровень уверенности:
   - **проверено** (отмечено по умолчанию) — только Яндекс ТВ: `com.yandex.tv.home`,
     `com.yandex.launcher.updaterapp`, `com.yandex.android.advid` (проверено на Tuvio);
   - **по отзывам** (не отмечено) — Google TV `setupwraith`, Android TV `tvrecommendations`,
     PatchWall `mitvplus`/`michannel`/`updateservice` и т. п.;
   - **родной экран** (не отмечено) — домашний экран платформы; предлагать отключать его нужно,
     только если после установки «Домой» всё ещё открывает его. Для Google TV — с предупреждением,
     что пропадут функции главного экрана Google TV.
   Google Play, сервисы Google, голосовой поиск, клавиатуры, настройки, входы HDMI, сервисы
   Яндекс ТВ/Алиса, сервисы Салют ТВ и системные пакеты TCL не трогаются никогда.
   Без установленного WhiteHole шаг не запускается. Перед отключением сохраняется резервная копия
   `%LOCALAPPDATA%\WhiteHoleSetup\backup-<модель>-<серийник>.json` (там же — исходный домашний экран).
5. **Вернуть как было** — включает обратно всё из резервной копии (без копии — отключённые пакеты
   из известных списков), возвращает тот домашний экран, что был до WhiteHole, по галочке удаляет WhiteHole.

На Android 6 и ниже домашний экран командой не меняется — программа попросит нажать «Домой»
и выбрать WhiteHole → «Всегда». Samsung (Tizen), LG (webOS), VIDAA, Apple TV не поддерживаются —
вариант: Android-приставка в HDMI или VPN на роутере.

Скачанные APK и резервные копии лежат в `%LOCALAPPDATA%\WhiteHoleSetup`.
Программа никуда ничего не отправляет: в интернет ходит только за двумя APK с GitHub.
Если что-то пошло не так — внизу «Подробности» → «Скопировать для поддержки», клиент присылает текст.

## Как пересобрать

Сборка идёт сама в GitHub Actions (`.github/workflows/tv-setup.yml`, runner `windows-latest`)
при каждом push в ветку `claude/whitehole-setup-win`, если менялась папка `tv-setup/`.
Можно запустить и вручную: Actions → «WhiteHole Setup (Windows)» → Run workflow.
Workflow прогоняет тесты, скачивает Google platform-tools (adb.exe + 2 dll), собирает
`WhiteHoleSetup.exe` через PyInstaller, проверяет, что adb внутри exe запускается,
и заменяет файл в релизе `tv-setup-latest`.

Запуск из исходников (для разработки):

```
cd tv-setup
pip install -r requirements.txt pytest
python -m pytest -q tests
python main.py
```

adb берётся из `tv-setup/bin/` или из PATH. Иконка пересоздаётся `python tools/make_icon.py`.

## Текст для клиента (бот / поддержка)

> 📺 Как поставить WhiteHole на телевизор с компьютера (Windows):
> 1. На телевизоре включи «Отладку по сети» (если не знаешь как — в программе есть кнопка «Как включить отладку на ТВ»).
> 2. Скачай программу: https://github.com/FEOLAR/testing/releases/download/tv-setup-latest/WhiteHoleSetup.exe
> 3. Запусти. Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
> 4. Нажми «Найти телевизор», на ТВ разреши отладку («Всегда разрешать» → ОК).
> 5. Нажми «Установить». Потом на телевизоре в WhiteHole нажми «Войти через Telegram» и отсканируй QR-код телефоном. Готово!
> Компьютер и телевизор должны быть подключены к одному роутеру.
