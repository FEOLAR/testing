# WhiteHole Setup — программа для Windows

Делает в пару кликов всё, что раньше делали руками через ADB:
находит телевизор в домашней сети, ставит лаунчер WhiteHole и Happ,
делает WhiteHole домашним экраном, может отправить подписку в Happ,
на Яндекс ТВ — убрать рекламу (и вернуть всё обратно).

## Где скачать

Последняя сборка всегда здесь:
https://github.com/FEOLAR/testing/releases/tag/tv-setup-latest

Прямая ссылка на файл:
https://github.com/FEOLAR/testing/releases/download/tv-setup-latest/WhiteHoleSetup.exe

Это один файл `WhiteHoleSetup.exe` (~20–30 МБ), установка не нужна: adb уже внутри.

### Предупреждение Windows (SmartScreen)

Программа не подписана сертификатом, поэтому при первом запуске Windows может показать
синее окно «Система Windows защитила ваш компьютер». Нажать **«Подробнее» → «Выполнить в любом случае»**.
Браузер (Chrome/Edge) тоже может спросить «Сохранить файл?» — выбрать «Сохранить» / «Всё равно сохранить».
Убрать предупреждение навсегда можно только платным сертификатом подписи кода.

## Что делает программа

1. **Найти телевизор** — проверяет домашнюю сеть (порт 5555), показывает модель. Можно ввести IP вручную.
   Если на ТВ появилось «Разрешить отладку?» — отметить «Всегда разрешать» и нажать ОК (программа ждёт 60 с).
2. **Установить** — скачивает свежие `whitehole-tv.apk` (релиз `tv-launcher-latest`) и `Happ.apk`
   (последний релиз Happ-proxy/happ-android), ставит их, делает WhiteHole домашним экраном.
   Happ не переустанавливается, если уже стоит (есть галочка «Переустановить»).
3. **Подписка** (по желанию) — ссылка из бота «Моя подписка» отправляется в Happ на ТВ
   диплинком `happ://add/<ссылка>`; на ТВ откроется Happ, клиент подтверждает пультом.
4. **Убрать рекламу** (для продвинутых, только Яндекс ТВ) — отключает только
   `com.yandex.tv.home`, `com.yandex.launcher.updaterapp`, `com.yandex.android.advid`
   (`pm disable-user --user 0`). Без установленного WhiteHole не запускается.
   Перед отключением сохраняет резервную копию
   `%LOCALAPPDATA%\WhiteHoleSetup\backup-<модель>-<серийник>.json`.
   Алиса, сервисы Яндекс ТВ, настройки и мастер настройки не трогаются.
5. **Вернуть как было** — включает обратно всё из резервной копии (или из известного списка),
   возвращает домашний экран Яндекса, по галочке удаляет WhiteHole.

Скачанные APK и резервные копии лежат в `%LOCALAPPDATA%\WhiteHoleSetup`.
Программа никуда ничего не отправляет: в интернет ходит только за двумя APK с GitHub.
Если что-то пошло не так — внизу «Подробности» → «Скопировать для поддержки», клиент присылает текст.

## Как пересобрать

Сборка идёт сама в GitHub Actions (`.github/workflows/tv-setup.yml`, runner `windows-latest`)
при каждом push в ветку `claude/whitehole-setup-win`, если менялась папка `tv-setup/`.
Можно запустить и вручную: Actions → «WhiteHole Setup (Windows)» → Run workflow.
Workflow прогоняет тесты, скачивает Google platform-tools (adb.exe + 2 dll), собирает
`WhiteHoleSetup.exe` через PyInstaller, проверяет, что adb внутри exe запускается,
и заменяет файл в релизе `tv-setup-latest`.

Запуск из исходников (для разработки):

```
cd tv-setup
pip install -r requirements.txt pytest
python -m pytest -q tests
python main.py
```

adb берётся из `tv-setup/bin/` или из PATH. Иконка пересоздаётся `python tools/make_icon.py`.

## Текст для клиента (бот / поддержка)

> 📺 Как поставить WhiteHole на телевизор с компьютера (Windows):
> 1. На телевизоре включи «Отладку по сети» (если не знаешь как — в программе есть кнопка «Как включить отладку на ТВ»).
> 2. Скачай программу: https://github.com/FEOLAR/testing/releases/download/tv-setup-latest/WhiteHoleSetup.exe
> 3. Запусти. Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
> 4. Нажми «Найти телевизор», на ТВ разреши отладку («Всегда разрешать» → ОК).
> 5. Нажми «Установить», затем вставь ссылку из «Моя подписка» → «Отправить в Happ». Готово!
> Компьютер и телевизор должны быть подключены к одному роутеру.
