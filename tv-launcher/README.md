# WhiteHole — лаунчер для Android TV

Домашний экран для телевизора: без рекламы, лёгкий, с кнопкой «Подключиться» (открывает Happ) и статусом защиты.

## 1. Скачать APK

Последняя сборка всегда лежит здесь:
https://github.com/FEOLAR/testing/releases/tag/tv-launcher-latest

Скачайте файл **whitehole-tv.apk** (например, в папку «Загрузки»).

## 2. Установить на телевизор (Windows PowerShell)

Откройте PowerShell в папке, где лежат `adb.exe` и `whitehole-tv.apk`, и выполните по одной строке:

```powershell
adb connect 192.168.3.19:5555
adb install -r whitehole-tv.apk
```

Если `adb` лежит в текущей папке и PowerShell его «не видит», пишите `.\adb` вместо `adb`.

## 3. Запустить

Через пульт: лаунчер появится в списке приложений под названием **WhiteHole**.

Или с компьютера:

```powershell
adb shell am start -n space.whitehole.tv/.MainActivity
```

## 4. Сделать домашним экраном

```powershell
adb shell cmd package set-home-activity space.whitehole.tv/.MainActivity
```

После этого нажмите на пульте кнопку «Домой». Если телевизор спросит, какой лаунчер использовать — выберите **WhiteHole** → «Всегда».

Важно: на Яндекс ТВ родной лаунчер может всё равно перехватывать кнопку «Домой». Следующий шаг — пришлите вывод команды

```powershell
adb shell pm list packages > tv-packages.txt
```

(файл `tv-packages.txt` появится в той же папке). По нему мы аккуратно отключим домашний экран и рекламу Яндекса так, чтобы ничего не сломать. Сами пакеты пока ничего не отключайте.

## 5. Обновить

Скачайте новый `whitehole-tv.apk` по той же ссылке и снова выполните:

```powershell
adb install -r whitehole-tv.apk
```

Настройки и избранное сохранятся.

## Как пользоваться

- **Главная** — статус («Защищено» / «Не подключено»), кнопки «Подключиться» и «Как подключить», ряд избранных приложений.
- **Приложения** — все установленные приложения. Чтобы добавить или убрать приложение из избранного на главной — удерживайте кнопку ОК или нажмите «Меню» на пульте.
- **Как подключить** — QR-код на бота @WhiteHoleVPNbot и короткая инструкция.
- Кнопка «Назад» на главной ничего не делает — так и задумано для домашнего экрана.

## Для разработчика

- Исходники: `tv-launcher/` (Kotlin, обычные Android View, без Compose/leanback).
- Сборка: GitHub Actions, workflow `.github/workflows/tv-launcher.yml` (Gradle 8.9, AGP 8.5.2, JDK 17). Результат — артефакт и релиз `tv-launcher-latest`.
- Ключ подписи `app/whitehole-tv.jks` хранится в репозитории намеренно, чтобы обновления ставились поверх старой версии.
